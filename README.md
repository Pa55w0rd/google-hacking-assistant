## 🔍 产品简介

Search Hacking 助手是一个 Chrome 浏览器扩展，旨在简化安全研究和渗透测试人员使用搜索引擎Hacking语法的过程。它会在包含 `site:` 查询的 Google、百度和Bing搜索结果页面自动注入一个**固定在右侧**的侧边栏，提供一系列预定义和可自定义的 Hacking 语法按钮。**通过灵活的语法配置（可独立开关内置及自定义规则），您可以轻松打造专属的 Hacking 工具集**，一键即可针对目标域名执行高级搜索。

## ✨ 功能特色

### 🎯 智能侧边栏注入
- **自动检测** - 仅在包含 `site:` 查询的搜索结果页面自动显示 Hacking 语法侧边栏
- **固定位置** - 始终固定在页面右侧，不影响搜索结果浏览
- **实时更新** - 在 Popup 或选项页中**更改设置（如启用/禁用侧边栏、启用/禁用语法）会实时反映在搜索页面上**，无需手动刷新

### 🚀 多搜索引擎支持
- **Google搜索** - 完整支持Google全球域名和各国版本
- **百度搜索** - 针对中文环境优化，支持百度特有的搜索语法
- **Bing搜索** - 支持Microsoft Bing全球版本
- **引擎控制** - 根据语法自身配置决定在哪个搜索引擎上显示

### 📋 URL提取工具
- **一键提取** - 提供"提取URL"功能，一键提取当前搜索结果中的所有URL
- **智能过滤** - 支持配置URL黑名单，自动过滤搜索结果中不需要的域名
- **多种匹配** - 支持精确匹配、子域名匹配和正则表达式匹配
- **快速复制** - 支持单个复制或批量复制，方便对搜索结果进行进一步分析

### ⚙️ 高度灵活的语法管理
- **内置语法** - 9个精心设计的内置语法，覆盖常见安全研究场景
- **自定义语法** - 不仅可以添加、编辑、删除自己的 Hacking 语法
- **精细控制** - 独立启用或禁用**每一条**内置语法和自定义语法，打造个性化的 Hacking 工具集
- **引擎选择** - 可以选择语法**支持的搜索引擎**，灵活控制语法在 Google、百度和Bing上的显示
- **动态替换** - 自动将语法中的 `{target_domain}` 占位符替换为当前搜索查询中的 `site:` 指定的域名

## ⚠️ 注意事项

### Google、百度和Bing搜索语法差异

虽然本扩展同时支持Google、百度和Bing搜索引擎，但请注意三者的搜索语法存在一些差异：

1. **语法兼容性**：
   - 某些高级搜索语法在Google上有效，但在百度或Bing上可能无效，反之亦然
   - 例如，`intext:`、`intitle:` 等指令在三个搜索引擎上的行为可能不完全一致

2. **搜索结果差异**：
   - 即使使用相同的语法，三个搜索引擎返回的结果也可能有显著差异
   - 这是由于各自的索引数据库和搜索算法不同导致的

3. **语法组合限制**：
   - 百度和Bing对复杂语法组合的支持可能不如Google完善
   - 在百度或Bing上使用多个高级指令组合时可能会忽略部分指令

建议在使用本扩展时，根据目标和需求选择合适的搜索引擎，并针对不同搜索引擎调整语法。如果某个语法在特定搜索引擎上不起作用，可以尝试简化语法或使用该搜索引擎特有的替代语法。

本扩展的内置语法已尽可能考虑三个搜索引擎的兼容性，但自定义语法时请注意这些差异。

## 🚀 安装使用

目前，你可以通过以下方式从源代码加载此扩展：

1.  **下载代码**：
    *   克隆此仓库：`git clone https://github.com/Pa55w0rd/google-hacking-assistant.git`
    *   或者，下载仓库的 ZIP 文件并解压缩。
2.  **打开 Chrome 扩展页面**：在浏览器地址栏输入 `chrome://extensions/` 并回车。
3.  **启用开发者模式**：在页面右上角找到并打开"开发者模式"开关。
4.  **加载扩展**：点击左上角的"加载已解压的扩展程序"按钮，然后选择你刚才下载并解压（或克隆）的项目文件夹。
5.  安装完成！你应该能在浏览器工具栏看到扩展图标。

## 📖 使用指南

### 基础使用
1.  **进行包含 `site:` 的搜索**：在 Google、百度或Bing搜索框中输入包含 `site:` 指令的查询，例如 `site:example.com test`，然后按回车进行搜索。
2.  **侧边栏出现**：在搜索结果页面加载完成后，如果扩展是启用的状态（默认启用），你应该能在页面**右侧看到固定位置的"Search Hacking 助手"侧边栏**。
    *   *注意*：如果搜索查询中没有 `site:` 指令，侧边栏不会显示。
3.  **点击语法按钮**：侧边栏会显示所有已启用且支持当前搜索引擎的内置语法和自定义语法按钮。点击你感兴趣的按钮。
4.  **执行 Hacking 搜索**：扩展会自动将该按钮对应的 Hacking 语法中的 `{target_domain}` 替换为 `example.com`，然后在新标签页执行这个新的搜索。

### 高级功能
- **提取URL**：点击侧边栏顶部的"提取URL"按钮，扩展会从当前搜索结果中提取所有URL，应用URL黑名单过滤，并显示在侧边栏的URL面板中。
- **管理扩展**：
    *   点击浏览器工具栏上的扩展图标，可以快速切换"启用侧边栏"的状态，或点击"打开设置"进入选项页面。
    *   在选项页面，你可以管理自定义语法（增删改查、启用/禁用、选择支持的搜索引擎）、**启用/禁用内置语法**、更改链接打开方式、配置URL黑名单。**充分利用语法的开关功能，定制您需要的侧边栏。**
    *   **所有设置更改（启用/禁用侧边栏、语法开关）都会实时应用到已打开的搜索页面，无需刷新。**

## 📌 添加或编辑自定义语法

这是发挥 Search Hacking 助手强大潜力的关键！除了使用内置语法，您还可以根据自己的特定需求，创建和管理个性化的 Hacking 语法。

在添加或编辑自定义语法时，你可以使用 `{target_domain}` 这个特殊的占位符。当你在搜索结果页面（包含 `site:example.com`）点击该语法按钮时，扩展会自动将语法中的 `{target_domain}` 替换成 `example.com`。

**示例：**

*   你保存了一个自定义语法：`site:{target_domain} inurl:admin`
*   你在 Google、百度或Bing搜索 `site:example.com`
*   在出现的侧边栏中点击了上述语法按钮
*   扩展将执行新的搜索：`site:example.com inurl:admin`

这使得您可以创建一次语法，就能方便地对任何通过 `site:` 指令指定的目标网站执行该搜索。

### 支持的搜索引擎设置

添加或编辑语法时，你可以勾选语法支持的搜索引擎（Google、百度和/或Bing）。语法只会在你指定的搜索引擎结果页面的侧边栏中显示。这使你能够为不同的搜索引擎定制不同的语法集。

### URL黑名单配置

在v2.0版本中，你可以配置URL黑名单来过滤搜索结果中的URL。黑名单支持以下几种匹配模式：

1. **普通域名匹配**：直接输入域名，如`example.com`，将匹配该域名及其所有子域名
2. **通配符子域名匹配**：使用格式`*.example.com`，将只匹配`example.com`的子域名，但不匹配`example.com`本身
3. **正则表达式匹配**：使用格式`/pattern/`，将使用正则表达式匹配URL，提供最灵活的过滤方式

URL黑名单对"提取URL"功能特别有用，可以帮助你过滤掉不需要的结果，专注于有价值的目标URL。

### 学习与灵感：Google Hacking Database (GHDB)

对于 Hacking 语法本身，如果您还不熟悉或者想寻找更多有趣的用法，强烈推荐查阅 [Exploit DB 上的 Google Hacking Database (GHDB)](https://www.exploit-db.com/google-hacking-database)。这是一个巨大的宝库，包含了大量用于发现漏洞和敏感信息的搜索语法，是学习和获取自定义语法灵感的好地方。

Search Hacking 助手

版本 2.0.0

产品简介

Search Hacking 助手是一款专为安全研究人员和渗透测试人员设计的浏览器扩展，一键触发Google和百度Hacking搜索语法，简化安全研究和渗透测试流程。

核心功能
  • 多搜索引擎支持 - 同时支持 Google 和百度搜索
  • 智能侧边栏 - 自动检测搜索查询并显示相关 Hacking 语法
  • 一键提取 URL - 快速从搜索结果中提取所有网址
  • 自定义语法 - 根据具体需求添加和管理自定义搜索语法
  • 灵活控制 - 精确控制功能启用状态和结果打开方式
免责声明

本扩展仅供安全研究和授权渗透测试使用。请勿用于未授权的安全测试或任何非法活动。使用者需承担因使用本扩展而产生的所有法律责任。

添加自定义语法

查看示例
语法示例：
site:{target_domain} intitle:index.of
site:{target_domain} filetype:pdf
site:{target_domain} inurl:admin
使用 {target_domain} 占位符表示搜索目标域名

使用 {target_domain} 作为目标域名的占位符，它会自动替换为 site: 指定的域名

选择此语法支持的搜索引擎，语法仅在选中的搜索引擎结果页显示

注意：Google Hacking 和百度 Hacking 语法存在一定差异，语法可能不完全兼容
